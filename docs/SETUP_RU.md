# Настройка постоянного хранения данных пилота

Эта инструкция поможет настроить сохранение отзывов участников пилота в постоянной базе данных.

## Зачем это нужно

На бесплатном хостинге Render данные, записанные на диск, **стираются** при каждом перезапуске или обновлении. Чтобы не потерять отзывы участников пилота, нужно подключить внешнюю базу данных PostgreSQL.

## Шаг 1: Создание бесплатной базы данных

### Вариант А: Neon (рекомендуется)

1. Откройте [neon.tech](https://neon.tech/)
2. Нажмите **Sign Up** (можно войти через GitHub)
3. После входа нажмите **Create Project**
4. Введите имя проекта: `metapelet-pilot`
5. Выберите регион: **Europe (Frankfurt)** или ближайший к вам
6. Нажмите **Create Project**
7. На странице проекта найдите строку подключения (Connection String)
8. Нажмите на глаз **👁** рядом с паролем, чтобы показать полную строку
9. Скопируйте строку вида: `postgresql://user:password@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`

### Вариант Б: Supabase

1. Откройте [supabase.com](https://supabase.com/)
2. Нажмите **Start your project** и войдите
3. Нажмите **New project**
4. Введите имя: `metapelet-pilot`
5. Придумайте пароль базы данных (запишите его!)
6. Выберите регион: **Central EU (Frankfurt)** или ближайший
7. Нажмите **Create new project** (создание займёт 1-2 минуты)
8. После создания перейдите в **Settings** → **Database**
9. Найдите раздел **Connection string** → **URI**
10. Скопируйте строку подключения (замените `[YOUR-PASSWORD]` на ваш пароль)

## Шаг 2: Добавление переменных окружения в Render

1. Откройте [dashboard.render.com](https://dashboard.render.com/)
2. Найдите ваш сервис **metapelet-app** и откройте его
3. Перейдите в **Environment** в левом меню
4. Нажмите **Add Environment Variable**
5. Добавьте первую переменную:
   - **Key**: `DATABASE_URL`
   - **Value**: вставьте скопированную строку подключения из Neon или Supabase
   - Нажмите **Add**

6. Добавьте вторую переменную:
   - **Key**: `ADMIN_TOKEN`
   - **Value**: придумайте секретный пароль (например: `pilot2026_secure_token_xyz`)
   - Нажмите **Add**

7. Нажмите **Save Changes** внизу страницы

**Важно:** Render автоматически перезапустит сервис после сохранения. Подождите 1-2 минуты.

## Шаг 3: Проверка работы

1. Откройте сайт [www.metapelet.org](https://www.metapelet.org/)
2. Пройдите анкету и отправьте тестовый отзыв
3. Проверьте, что база данных создалась:
   - **Neon**: откройте ваш проект → Tables (должны появиться таблицы `pilot_events` и `pilot_feedback`)
   - **Supabase**: Table Editor → должны появиться две таблицы

## Шаг 4: Скачивание отзывов (CSV)

Когда накопятся отзывы участников, вы можете скачать их в формате CSV:

1. Откройте в браузере:
   ```
   https://www.metapelet.org/admin/feedback.csv?token=ВАШ_ADMIN_TOKEN
   ```
   
   Замените `ВАШ_ADMIN_TOKEN` на пароль, который вы указали в `ADMIN_TOKEN` на шаге 2.

2. Браузер скачает файл `metapelet-feedback.csv`

3. Откройте файл в Excel, Google Sheets или Numbers

### Пример URL:
```
https://www.metapelet.org/admin/feedback.csv?token=pilot2026_secure_token_xyz
```

## Что хранится в базе данных

В базе сохраняются **только анонимные данные**:

- ✅ Оценки комфорта, интереса, желания продолжить
- ✅ Текст отзыва (что понравилось/не понравилось)
- ✅ Язык разговора (русский/иврит/английский)
- ✅ Время отправки отзыва
- ✅ Анонимный идентификатор сессии

**Не хранятся:**
- ❌ Имена участников
- ❌ Возраст
- ❌ Телефоны
- ❌ Адреса
- ❌ Текст разговоров

Это соответствует политике конфиденциальности сайта.

## Лимиты бесплатных планов

### Neon (бесплатный план)
- 0.5 ГБ хранилища (достаточно для тысяч отзывов)
- 1 проект
- База спит после 5 минут неактивности (но данные не теряются)

### Supabase (бесплатный план)
- 500 МБ базы данных
- 2 проекта
- База не спит

### Render (бесплатный план)
- 750 часов работы в месяц на аккаунт
- Сервис спит после 15 минут неактивности
- **Важно:** Если на вашем аккаунте Render есть другие бесплатные веб-сервисы, 750 часов делятся между ними!

## Отключение автоматических пингов (если нужно)

Если 750 часов в месяц не хватает из-за других сервисов, можно отключить автоматические пинги:

1. Откройте репозиторий на GitHub
2. Перейдите в **Settings** → **Actions** → **General**
3. Выберите **Disable actions**
4. Сайт будет «засыпать» через 15 минут, но просыпаться при первом заходе (холодный старт ~30 секунд)

## Помощь

Если что-то не работает:
- Проверьте строку подключения `DATABASE_URL` в Render Environment
- Посмотрите логи Render: откройте ваш сервис → вкладка **Logs**
- Убедитесь, что в Neon/Supabase появились таблицы `pilot_events` и `pilot_feedback`

Если в логах ошибка `psycopg2` — перезапустите сервис через Render (Manual Deploy → Clear build cache & deploy).
