# MetaPelet

Тёплый голосовой собеседник для пожилых людей. Задача MetaPelet — не заменить человека, а сделать так, чтобы у пожилого человека было меньше часов одиночества между встречами с близкими и визитами сиделки.

MetaPelet — не медицинское устройство: он не даёт медицинских советов и не напоминает о лекарствах. Это собеседник для эмоциональной поддержки.

## Живое демо

- Основной сайт: https://www.metapelet.org
- Голосовая страница: https://kristina130276.github.io/metapelet-voice-page/?id=mp_0001

Как попробовать: открыть сайт → «Поговорить» → короткая анкета (имя, возраст, язык) → голосовой разговор.
На бесплатном хостинге первая загрузка может занять 20–40 секунд («засыпающий» сервис).

## Что в этом репозитории

Это **браузерная (веб) версия** MetaPelet.

- Backend: Flask (`app.py`), деплой на Render (`render.yaml`, `Procfile`, `start.sh`).
- Голос: Google Cloud Text-to-Speech (маршрут `/tts`).
- Диалоговая модель: Anthropic Claude Haiku (миграция на OpenAI GPT-5.6 — в процессе).
- Фронтенд: `index.html` (анкета → голосовой чат).
- Языки: русский, иврит, английский.
- Промпты: `prompts/base_metapelet.txt` (+ пример профиля).

## Локальный запуск

```bash
pip install -r requirements.txt

# переменные окружения (не коммитить):
#   ANTHROPIC_API_KEY=...   — диалог (браузерная версия)
#   GOOGLE_API_KEY=...      — озвучка (Google TTS)

python app.py
# открыть http://localhost:5000
```

Продакшн-запуск: `gunicorn app:app` (см. `render.yaml`).

## Постоянное хранение данных пилота

По умолчанию отзывы записываются в локальные файлы (ephemeral на Render). Для production настройте:

1. **DATABASE_URL** — PostgreSQL connection string (Neon, Supabase, etc.)
2. **ADMIN_TOKEN** — секретный токен для скачивания отзывов

Без `DATABASE_URL` система автоматически работает с файлами. При наличии `DATABASE_URL` все данные сохраняются в базу данных.

Экспорт отзывов: `https://www.metapelet.org/admin/feedback.csv?token=YOUR_ADMIN_TOKEN`

Подробная инструкция на русском: [docs/SETUP_RU.md](docs/SETUP_RU.md)

## Автоматический keep-alive (без холодных стартов)

GitHub Actions пингует `/health` каждые 10 минут, чтобы Render free tier не засыпал. Workflow: `.github/workflows/keep-alive.yml`

**Важно:** Render free tier даёт 750 часов в месяц **на аккаунт**. Если у вас несколько бесплатных веб-сервисов, часы делятся между ними. Эта настройка работает только если `metapelet-app` — единственный бесплатный сервис на вашем Render аккаунте.
