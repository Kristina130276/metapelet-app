# MetaPelet

Тёплый голосовой собеседник для пожилых людей. Задача MetaPelet — не заменить человека, а сделать так, чтобы у пожилого человека было меньше часов одиночества между встречами с близкими и визитами сиделки.

MetaPelet — не медицинское устройство: он не даёт медицинских советов и не напоминает о лекарствах. Это собеседник для эмоциональной поддержки.

## Живое демо

- Основной сайт: https://www.metapelet.org
- Голосовая страница: https://kristina130276.github.io/metapelet-voice-page/?id=mp_0001

Как попробовать: открыть сайт → «Поговорить» → короткая анкета (имя, возраст, язык) → голосовой разговор.
На бесплатном хостинге первая загрузка может занять 20–40 секунд («засыпающий» сервис).

## Что в этом репозитории

Это **браузерная (веб) версия** MetaPelet.

- Backend: Flask (`app.py`), деплой на Render (`render.yaml`, `Procfile`, `start.sh`).
- Голос: Google Cloud Text-to-Speech (маршрут `/tts`).
- Диалоговая модель: OpenAI GPT-5.6 (`gpt-5.6`) по умолчанию; Anthropic Claude Haiku остаётся fallback-провайдером через `MODEL_PROVIDER=anthropic`.
- Фронтенд: `index.html` (анкета → голосовой чат).
- Языки: русский, иврит, английский.
- Промпты: `prompts/base_metapelet.txt` (+ пример профиля).

## Использование OpenAI в проекте

Основной рабочий голосовой прототип MetaPelet — это отдельный кастомный GPT-агент, созданный в ChatGPT, который тестируется с пожилыми людьми около года. Браузерная версия в этом репозитории — дополнительная разработка.

В браузерной версии маршрут `POST /chat` в `app.py` теперь по умолчанию использует OpenAI GPT-5.6 с актуальным alias-моделью `gpt-5.6` (он направляет запросы к GPT-5.6 Sol). Сервер создаёт OpenAI-клиент из переменной окружения `OPENAI_API_KEY`, передаёт системный промпт первым сообщением `role="system"`, затем добавляет текущую историю диалога пользователя и очищает ответ через существующую функцию `strip_emojis()`.

Anthropic Claude Haiku сохранён как fallback-провайдер без изменения пользовательского сценария: если нужно временно вернуть прежний диалоговый backend, установите `MODEL_PROVIDER=anthropic` и задайте `ANTHROPIC_API_KEY`. Значение по умолчанию — `MODEL_PROVIDER=openai`.

Codex помог на этапе интеграции: обновил серверный маршрут `/chat`, зависимости, переменные Render и документацию, сохранив текущий фронтенд, анкету и Google TTS без функциональных изменений.

## Локальный запуск

```bash
pip install -r requirements.txt

# переменные окружения (не коммитить):
#   OPENAI_API_KEY=...      — диалог по умолчанию (OpenAI GPT-5.6)
#   MODEL_PROVIDER=openai   — по умолчанию; можно поставить anthropic для fallback
#   ANTHROPIC_API_KEY=...   — диалог при MODEL_PROVIDER=anthropic
#   GOOGLE_API_KEY=...      — озвучка (Google TTS)

python app.py
# открыть http://localhost:5000
```

Продакшн-запуск: `gunicorn app:app` (см. `render.yaml`).
